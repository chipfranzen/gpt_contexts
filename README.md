# Tool Context Profiles

This repository contains my personal context profiles for niche tools, so I can share them with ChatGPT or others when asking questions.
Each profile defines:
- Version and environment
- References (cheat sheets, tutorials, docs)
- My custom workflow notes
- Known quirks or pitfalls
- Preferred answer style

## How I use this
When I ask a question, I link the relevant profile:

```
Context:

    Tool: sc-im

    Version: 0.8.3

    Profile: https://github.com/chipfranzen/tool-contexts/blob/main/sc-im.md

Question:
<my question>
```
